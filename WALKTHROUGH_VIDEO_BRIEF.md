# PromptForge Product Walkthrough Video Brief

## Format and purpose

This walkthrough is a polished **16:9 landscape product tutorial** for new PromptForge users. It uses the live Workshop Noir visual language and explains the public product journey in plain English. The video must demonstrate real pages and workflows rather than inventing unavailable features.

## Storyboard

| Segment | Page or action | On-screen guidance |
|---|---|---|
| Opening | Builder homepage | Introduce PromptForge and the Builder as the starting point. |
| Build a prompt | Builder | Choose a category, answer the guided brief, inspect the live output, then copy or refine it. |
| Find a template | Library | Use search, category filters, access filters, sorting, and Load more work orders. |
| Access | Pricing and account context | Explain free prompts, locked work orders, signing in, and unlocking full access without exposing codes or credentials. |
| Learn | Guides and About | Show practical guides, the editorial profile, and PromptForge’s mission. |
| Get help | Contact | Show the contact form and direct WhatsApp contact path. |
| Personalize | Header theme control | Demonstrate dark, light, and system theme choices plus responsive navigation. |
| Closing | Builder and Library | Reinforce the build, browse, learn, and contact path. |

## Accuracy constraints

The video should not depict an authenticated account, code redemption, admin controls, a completed purchase, personal information, or any fabricated testimonials. It should use the exact text-only **PROMPTFORGE** branding and dark industrial orange-and-charcoal Workshop Noir palette.
