# Google SEO guidance notes

Google Search Central states that Organization structured data on the homepage or a page describing the organization can help Google understand administrative details and disambiguate the organization. It recommends adding only properties that apply and validating the markup with the Rich Results Test.

Google also states that structured data should describe information visible on the page; it should not be added for content that is not visible. FAQ markup is therefore limited to the questions and answers visibly presented on PromptForge’s Contact page.

Google’s link guidance says crawlable links should use an anchor element with an href, descriptive anchor text, and natural context. It recommends cross-referencing important internal pages and obtaining external links naturally rather than using keyword-stuffed or paid/untrusted links.
