# PromptForge backlink outreach foundation

PromptForge should earn external links from relevant places where the product is genuinely useful. The first targets should be the founder’s verified professional profiles, the company’s Google Business Profile if eligible, Nigerian technology and startup directories, creator and marketing communities that allow useful resource links, and guest contributions to publications focused on AI productivity, content operations, freelancing, and customer engagement.

Each placement should point to the most relevant page rather than always linking to the homepage. A directory profile can link to `/about`; a practical tutorial can link to `/guides/prompt-engineering` if that route is later created; and a resource mention can link to `/library` or `/pricing` when the surrounding copy makes that destination useful. Use descriptive, natural anchor text such as “PromptForge’s structured AI prompt builder,” not repeated exact-match keywords.

## Quality rules

Only request links from pages whose audience is relevant to PromptForge. Do not buy links, exchange links at scale, publish duplicate guest articles, or claim customer results that have not been documented. Keep a simple outreach log with the site, page, contact, date, requested destination, and outcome. Review links quarterly and ask for corrections when a placement becomes misleading or irrelevant.
